Panduan Publikasi ke GitHub & GitHub Pages

Aplikasi Lab Maya ini dirancang dalam satu file HTML mandiri (index.html) sehingga dapat langsung di-hosting secara gratis menggunakan GitHub Pages:

# 1. Inisialisasi repository lokal & commit file index.html
git init
git add index.html
git commit -m "Deploy Virtual Lab Bab 5B DNS & Email Server"
# 2. Hubungkan ke repository GitHub baru & push
git branch -M main
git remote add origin https://github.com/USERNAME/lab-maya-dns-mail.git
git push -u origin main
  1. Buka repository Anda di GitHub.com → masuk ke tab Settings.
  2. Pada menu sebelah kiri, pilih Pages (di bawah bagian Code and automation).
  3. Pada bagian Build and deployment → Branch, pilih main dan folder / (root), lalu klik Save.
  4. Tunggu ±1 menit, tautan situs Lab Maya Anda akan aktif di https://USERNAME.github.io/lab-maya-dns-mail/.
