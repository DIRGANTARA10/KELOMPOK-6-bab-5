Teori Singkat: Integrasi DNS & Email Server

1. Peran DNS dalam Layanan Email

Agar email dapat dikirim ke domain tujuan (misalnya smkn2.sch.id), server pengirim tidak bisa langsung menebak alamat IP tujuan. Diperlukan dua jenis record utama pada DNS Server (seperti BIND9):

  • MX Record (Mail Exchanger): Menunjuk nama host server yang bertanggung jawab menerima email untuk domain tersebut (contoh: smkn2.sch.id → mail.smkn2.sch.id).
  • A Record (Address Record): Menerjemahkan hostname Mail Server menjadi alamat IPv4 fisik (contoh: mail.smkn2.sch.id → 192.168.10.5).

2. Komponen & Protokol Email Server

SMTP (Port 25 / 587)

Simple Mail Transfer Protocol bertugas mendorong/mengirim email dari Client (MUA) ke Mail Server (MTA) maupun antar Mail Server.

IMAP (Port 143 / 993)

Internet Message Access Protocol menyinkronkan kotak masuk antara server (MDA) dan perangkat penerima tanpa menghapus email di server.

POP3 (Port 110 / 995)

Post Office Protocol v3 mengunduh email dari server ke perangkat lokal penerima (umumnya menghapus salinan di server).

Instruksi Praktikum Lab Maya

1

Pengujian Normal (Integrasi Berhasil)

Pastikan zona DNS memiliki MX Record untuk domain tujuan (smkn2.sch.id → mail.smkn2.sch.id) dan A Record untuk host mail (mail.smkn2.sch.id → 192.168.10.5). Klik Kirim & Simulasikan lalu amati pergerakan paket DNS, SMTP, dan IMAP.

2

Analisis Kegagalan DNS (Troubleshooting)

Klik tombol Simulasi Error (atau hapus MX/A record secara manual pada panel kiri). Jalankan kembali simulasi dan catat pada tahap mana pengiriman email terhenti serta pesan kesalahan yang muncul di panel Log.

3

Uji Domain Kustom Kelompok

Tambahkan record DNS baru menggunakan nama domain kelompokmu (contoh: kelompok1.net). Ubah alamat email pengirim dan penerima sesuai domain baru tersebut, lalu buktikan bahwa email berhasil diterima di Kotak Masuk Client B.

4

Pengisian Lembar Kerja (LKPD)

Buka menu Pertanyaan LKPD di pojok kanan atas, jawab seluruh pertanyaan analisis berdasarkan hasil pengamatan simulasi, lalu cetak atau simpan hasil jawabanmu.

Lembar Kerja Peserta Didik (LKPD) - Bab 5B

1. Mengapa proses pengiriman email membutuhkan dua kali proses resolusi DNS (MX Record terlebih dahulu, baru kemudian A Record)?

Kunci Pembahasan: MX Record hanya memberikan nama host (FQDN) dari Mail Server tujuan (misal mail.smkn2.sch.id), bukan alamat IP. Oleh karena itu, sistem wajib melakukan query A Record untuk menerjemahkan hostname Mail Server tersebut menjadi alamat IP tujuan pengiriman paket.

2. Berdasarkan percobaan "Simulasi Error" (ketika MX Record hilang atau A Record tidak mengarah ke IP Mail Server), apa dampak yang terjadi pada protokol SMTP?

Kunci Pembahasan: Koneksi SMTP tidak pernah terjadi (gagal sebelum transmisi) karena pengirim tidak mengetahui alamat IP server tujuan (NXDOMAIN / Host Unreachable), sehingga pesan gagal dikirim dan dikembalikan ke pengirim (Mail Delivery Subsystem / Bounce).

3. Jelaskan perbedaan fungsi antara protokol SMTP (Port 25) dan IMAP (Port 143) dalam alur pengiriman hingga pembacaan email pada simulasi di atas!

Kunci Pembahasan: SMTP berfungsi mengirim (push) email dari Client A menuju Mail Server dan meneruskannya ke kotak surat tujuan. Sedangkan IMAP berfungsi mengambil dan menyinkronkan (pull/sync) email yang tersimpan di Mail Server agar dapat dibaca oleh Client B.
